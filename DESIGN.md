# Macro Longevity design

Warm ivory, evergreen, and local Inter define the shared system in `css/variables.css`. Page introductions use a dark evergreen surface. Actions, reading fields, and progress use native controls, visible focus, and plain-language status.

Use one primary navigation per page. Keep the six main destinations in the desktop header and at the bottom on phones. Page shortcuts sit in a sticky left rail when the viewport has room and below the introduction otherwise. Preserve mobile safe areas and allow the page to scroll naturally.

Review the 390px and 1440px layouts, keyboard focus, long labels, and the installed app shell when changing shared styles.
